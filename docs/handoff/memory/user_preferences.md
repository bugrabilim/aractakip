## Kullanıcı: Buğra Bilim

Araç Takip uygulamasının sahibi ve tek geliştiricisi. Türkiye'de yaşıyor.

## Çalışma Tercihleri

- **Dil:** Türkçe (arayüz + konuşma dili)
- **Karar verme:** Soru sormadan mantıklı kararı kendin ver, devam et
- **Stil:** Sadece inline JS objeleri (`T` nesnesi) — Tailwind/CSS ekleme
- **İkon:** Sadece lucide-react@0.383.0 — başka kütüphane ekleme
- **Grafik:** Sadece recharts — başka kütüphane ekleme
- **Kod değişikliği sonrası:** Önce `repo/src/App.jsx`'e ekle, test et, sonra `yakit-takip-drivvo.jsx`'a da kopyala (ikisi senkron tutulmalı)
- **Büyük değişikliklerde:** `npm run build` ile production build test et

## İletişim

- Kısa ve net cevap tercih eder
- Master dokümanı referans olarak kullanır (`MASTER_DOKUMAN.md`)
